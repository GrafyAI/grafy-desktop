# Grafy Desktop

Installers for **Grafy Desktop**, the desktop app for [Grafy](https://grafy.ai).

**Download the latest version from [grafy.ai/downloads](https://grafy.ai/downloads).**

| Platform | File |
|---|---|
| Windows 10 and 11 (64-bit) | [Grafy-Setup-x64.exe](https://github.com/GrafyAI/grafy-desktop/releases/latest/download/Grafy-Setup-x64.exe) |
| Linux (AppImage, 64-bit) | [Grafy-x86_64.AppImage](https://github.com/GrafyAI/grafy-desktop/releases/latest/download/Grafy-x86_64.AppImage) |
| Linux (Debian and Ubuntu, 64-bit) | [Grafy-amd64.deb](https://github.com/GrafyAI/grafy-desktop/releases/latest/download/Grafy-amd64.deb) |

An installed copy updates itself: when a newer version is published here, the
app offers a **Restart to update** button.

This repository holds release files only. Every release is listed under
[Releases](https://github.com/GrafyAI/grafy-desktop/releases).
